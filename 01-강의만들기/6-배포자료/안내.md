# 6단계 · 배포자료

**하는 일** 수강생에게 나눠줄 안내 페이지를 만듭니다. 단계마다 하는 일, 준비할 것, 복사 버튼이 붙은 프롬프트가 들어갑니다.

**준비할 것**

- 구조 설계서 또는 프롬프터

## 복사할 프롬프트 · 배포 페이지 만들기

```text
이 강의를 들은 수강생에게 나눠줄 안내 페이지를 만들어 주세요.

- 형식: HTML 파일 하나, 휴대폰에서도 잘 보이게
- 강의에서 보여준 단계마다: 하는 일 한 줄 / 준비할 것 / 복사해서 쓸 프롬프트
- 프롬프트마다 복사 버튼을 붙여 주세요
- 수강생이 직접 채울 부분은 [ ] 로 표시해 주세요
- 강의 내용에 없는 약속, 숫자, 후기는 넣지 않습니다

강의 내용: [구조 설계서 또는 프롬프터 붙여넣기]
```

## 마음에 안 들면 이렇게 말하세요

- "휴대폰에서 글자가 너무 작아요. 본문 글자를 키워 주세요."
- "복사 버튼을 눌러도 복사가 안 돼요. 원인을 찾아서 고쳐 주세요."

## AI 도구(Claude Code·Codex)가 진행할 때

1. 설계서·프롬프터를 읽고 `내작업/배포페이지.html`을 만든다. 색은 장표와 같은 세 가지를 쓴다.
2. 글꼴은 Pretendard CDN 한 줄로 불러오고, 외부 스크립트는 쓰지 않는다.
3. 복사 버튼은 `navigator.clipboard`가 막힌 환경(파일로 직접 연 경우 등)을 위해 텍스트 선택 방식 대체 코드를 함께 넣는다.
4. 사용자에게 휴대폰 크기로 열어 보고 복사 버튼을 한 번 눌러 보라고 안내한다.
5. 페이지를 인터넷에 올리는 일(배포)은 사용자가 결정한다. 대신 올리지 않는다.
