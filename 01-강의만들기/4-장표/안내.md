# 4단계 · 장표

**하는 일** 확정한 구조 설계서를 넣어 발표용 장표를 만듭니다. 디자인 규칙을 같이 주면 결과가 깔끔해집니다.

**준비할 것**

- 3단계에서 확정한 구조 설계서
- 내가 쓸 색 세 가지 (배경·글자·강조). 없으면 기본값: 아이보리 `#F7F4EC` · 검정 `#131313` · 코발트 `#0047AB`

**이 폴더의 파일**

- `예시-덱.html` — 더블클릭해서 브라우저로 열고 방향키로 넘겨 보세요. 완성된 모습입니다
- `lecture-deck/` — Claude Code·Codex가 장표를 만들 때 따르는 규칙(SKILL.md)과 스타일 파일. Claude Code에서는 저장소의 `.claude/skills/lecture-deck/`에 같은 파일이 있어 자동으로 인식됩니다

## 복사할 프롬프트 · 장표 만들기 (채팅용)

```text
위 구조 설계서대로 발표용 장표를 만들어 주세요.

형식
- HTML 파일 하나. 브라우저로 열어서 키보드 방향키로 넘길 수 있게
- 16:9 화면, 글꼴은 Pretendard
- 배경색 [예) 아이보리 #F7F4EC], 글자색 [예) 검정 #131313], 강조색 [예) 코발트 #0047AB] 한 가지

디자인 규칙
- 한 장에 문장 하나. 설명은 제가 말로 합니다
- 테두리 친 상자, 카드 모양은 쓰지 않습니다
- 글자 크기는 큰 제목 / 보조 문장 / 작은 라벨 세 단계만
- 강조색은 한 장에 한 곳만
- 설계서에 없는 숫자나 사례는 넣지 않습니다
```

> 디자인 규칙은 공냥(gongnyang)님의 ReelForge 저장소 디자인 규칙을 옮긴 것입니다. https://github.com/gongnyang/reelforge

## 마음에 안 들면 이렇게 말하세요

- "[5]번 장은 글자가 너무 많아요. 한 문장만 남겨 주세요."
- "강조색이 두 군데 들어간 장이 있어요. 장마다 한 곳만 남겨 주세요."

## 색 바꾸는 법

장표 HTML 파일 위쪽 `:root{` 줄에서 세 값만 바꾸면 됩니다.

```css
--bg:#F7F4EC;     /* 배경 */
--ink:#131313;    /* 글자 */
--accent:#0047AB; /* 강조 */
```

## AI 도구(Claude Code·Codex)가 진행할 때

1. `lecture-deck/SKILL.md`를 읽고 그 규칙대로 만든다.
2. `예시-덱.html`의 구조(`#bar`, `#stage`, `#hud`, `<section>`)를 그대로 쓰고, 슬라이드만 설계서대로 바꿔 `내작업/deck.html`로 저장한다.
3. 설계서 장수와 `<section>` 수가 같은지, 장마다 `.acc`가 한 번 이하인지 확인한다.
4. 사용자에게 파일을 열어 넘겨 보라고 하고, 고칠 장 번호를 받는다.
