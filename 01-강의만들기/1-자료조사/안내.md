# 1단계 · 자료조사를 대화로

**하는 일** 검색 대신 AI에게 묻고, 넓게 → 좁게 → 근거 확인 순서로 질문을 좁혀 갑니다. 답을 받는 게 아니라 질문을 좁혀 가는 과정입니다.

**준비할 것**

- 강의 주제
- 누구에게 가르치는지
- 지금 제일 궁금한 것

## 복사할 프롬프트 · 자료조사 시작

`[ ]` 안을 내 내용으로 바꿔 주세요.

```text
저는 [강의 주제]로 강의를 준비하는 강사입니다.
수강생은 [누구: 예) AI를 처음 써 보는 1인 사업자]입니다.

지금은 강의를 만들기 전 자료조사 단계입니다. 아직 목차나 강의안은 만들지 마세요.
아래 순서로 저와 대화해 주세요.

1. 이 주제로 강의하려면 강사가 알아야 할 것을 넓게 정리해 주세요.
2. 이 수강생들이 가장 막히는 지점이 어디일지 좁혀서 알려 주세요.
3. 말한 내용마다 근거가 어디에 있는지 함께 적어 주세요. 근거가 확실하지 않으면 확실하지 않다고 표시해 주세요.

마지막에 제가 더 좁혀서 물어볼 만한 질문 3개를 제안해 주세요.
```

## 질문을 좁혀 가는 세 가지 말

- 넓게: "이 주제로 강의하려면 뭘 알아야 해?"
- 좁게: "[수강생]이 제일 막히는 곳은 어디야?"
- 확인: "그 말의 근거가 어디에 있어?"

## 마음에 안 들면 이렇게 말하세요

- "너무 넓어요. [수강생]이 첫 수업에서 막히는 것만 다시 알려 주세요."
- "근거를 못 댄 내용은 빼고 다시 정리해 주세요."

## AI 도구(Claude Code·Codex)가 진행할 때

1. 사용자에게 강의 주제, 수강생, 지금 궁금한 것 세 가지를 묻는다.
2. 위 프롬프트의 1~3을 순서대로 진행한다. 웹 검색이 가능하면 근거 링크를 붙이고, 불가능하면 "확인 필요"로 표시한다.
3. 결과를 보여주고, 더 좁힐 질문 3개를 제안한 뒤 사용자 답을 기다린다.
4. 사용자가 "다음"이라고 하면 `2-내데이터/안내.md`로 넘어간다.
