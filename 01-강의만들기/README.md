# 01 · 강의 만들기 6단계

AI에게 "강의 만들어줘" 한 번으로 시키면 그럴듯하지만 누구의 강의도 아닌 결과가 나옵니다. 여섯 단계로 나눠 대화하고, 단계마다 내가 고치면 내 강의가 됩니다.

| 단계 | 폴더 | 하는 일 | 결과물 |
|---|---|---|---|
| 1 | `1-자료조사/` | 검색 대신 AI와 대화로 넓게 → 좁게 → 근거 확인 | 자료조사 대화 |
| 2 | `2-내데이터/` | 지난 강의자료·녹음 받아쓴 글·자주 받는 질문 넣기 | 나만의 설명 방식 정리 |
| 3 | `3-구조설계서/` | 장표 전에 뼈대 문서 한 장 | 구조 설계서 |
| 4 | `4-장표/` | 설계서로 발표용 장표 만들기 | `deck.html` |
| 5 | `5-프롬프터/` | 장표마다 말할 것·손으로 할 것·막혔을 때 | 진행 대본 |
| 6 | `6-배포자료/` | 수강생에게 나눠줄 안내 페이지 | 안내 페이지 HTML |

## 진행 방법

- **채팅으로 할 때**: ChatGPT나 Claude의 **같은 대화창**에서 1단계부터 순서대로 프롬프트를 붙여 넣으세요. 앞 단계 내용을 AI가 기억한 채로 이어집니다.
- **Claude Code·Codex에 맡길 때**: "01-강의만들기 1단계부터 같이 하자"라고 말하세요. AI가 각 폴더의 `안내.md`를 읽고 한 단계씩 확인받으며 진행합니다.

## 원칙 세 가지

1. 한 번에 끝내지 않는다. 단계마다 확인하고 고친다.
2. 내 자료에 없는 숫자·후기·사례는 넣지 않는다.
3. 설계서가 확정되기 전에는 장표를 만들지 않는다.
