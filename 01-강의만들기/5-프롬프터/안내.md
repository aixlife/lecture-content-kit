# 5단계 · 프롬프터

**하는 일** 장표마다 말할 것, 손으로 할 것, 막혔을 때 할 것을 적은 진행 대본을 만듭니다. 말로 설명하지 못하는 자료는 아직 완성이 아닙니다.

**준비할 것**

- 완성한 장표 (파일 또는 장표 문장 목록)
- 내 말투 설명 한 줄 (예: 짧은 존댓말, 과장 없음)

**이 폴더의 파일**

- `템플릿.md` — 빈 프롬프터
- `예시-프롬프터.md` — 채운 모습 예시 (형식만 참고하세요)

## 복사할 프롬프트 · 프롬프터 만들기

```text
완성된 장표를 보고, 발표할 때 옆 화면에 띄워 둘 진행 대본(프롬프터)을 만들어 주세요.

장표: [장표 파일 첨부 또는 장표 문장 목록 붙여넣기]

장표마다 아래 세 가지를 나눠 적어 주세요.
1. 말할 내용: 제가 그대로 읽어도 되는 문장. 제 말투는 [예) 짧은 존댓말, 과장 없음]
2. 손으로 할 것: 화면 전환, 시연 창 열기, 자료 띄우기 같은 동작
3. 막혔을 때: 시연이 안 되거나 질문이 나왔을 때 할 말과 대체 방법

맨 앞에는 시작 전 준비물 체크리스트(열어 둘 것, 닫아 둘 것)를 넣고, 각 부 앞에는 시작 시각을 적어 주세요.
```

## 마음에 안 들면 이렇게 말하세요

- "말할 내용이 딱딱해요. 제 녹음 말투처럼 더 짧게 바꿔 주세요."
- "[3]번 장 시연이 안 될 때 대신 보여줄 화면을 정해 주세요."

## AI 도구(Claude Code·Codex)가 진행할 때

1. `내작업/deck.html`(또는 사용자가 알려준 장표)과 구조 설계서를 읽는다.
2. `템플릿.md` 표기법으로 `내작업/프롬프터.md`를 만든다. 말투는 2단계에서 정리한 사용자 말투를 따른다.
3. HTML로 원하면 `4-장표/lecture-deck/assets/script.css`를 써서 `내작업/script.html`로 만든다.
4. 장표 수와 프롬프터의 장 수가 같은지 확인하고, 대본이 한 줄뿐인 장을 사용자에게 알려준다.
