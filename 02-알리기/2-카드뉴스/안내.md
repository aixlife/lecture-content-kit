# 2 · 글 → 카드뉴스

**하는 일** 내가 좋다고 본 카드뉴스를 먼저 분석해 규칙을 만들고, 그 규칙으로 내 글을 카드뉴스로 옮깁니다.

**준비할 것**

- 잘 된다고 본 카드뉴스 캡처 3~5개 (분석용으로만 씁니다. 남의 카드뉴스를 그대로 따라 만들지 않습니다)
- 앞 단계에서 쓴 블로그 글

**이 폴더의 파일**

- `규칙-예시.md` — 레퍼런스를 분석해서 뽑은 규칙 9개 예시
- `template/` — 1080x1350 카드뉴스 HTML 8장과 공통 스타일, 이미지로 뽑는 스크립트
- 결과 예시 이미지: 저장소의 `docs/card-example.png`

## 복사할 프롬프트 · 1) 레퍼런스 분석

```text
제가 좋다고 본 카드뉴스 [3~5]개를 첨부합니다. 카드뉴스마다 첫 장부터 마지막 장까지 캡처했습니다. 빠진 장은 '확인 불가'로 적어 주세요. 제 분야는 [분야]입니다.

캡처마다 아래를 표로 정리해 주세요.
- 첫 장 문장과 글자 수, 줄 수
- 첫 장이 눈길을 끄는 방식 (결과 숫자 / 궁금증 / 통념 뒤집기 등)
- 배경색, 글자색, 강조색 개수
- 장별 흐름 (문제 → 방법 → 요약 등)
- 마지막 장에서 무엇을 하게 하는지

마지막에 공통점을 제 카드뉴스에 적용할 규칙 [5~9]개로 정리해 주세요. 캡처에서 확인되지 않는 반응 수치는 쓰지 마세요.
```

## 복사할 프롬프트 · 2) 카드뉴스 만들기

```text
위 규칙으로 아래 글을 카드뉴스 [8]장으로 만들어 주세요.

글: [블로그 글 붙여넣기]

1. 먼저 장별 기획표를 주세요: 장 번호 / 역할(첫 장·문제·방법·요약) / 큰 제목(두 줄, 20자 안팎) / 본문(두 줄 이내)
2. 제가 확인하면 장마다 1080x1350 크기 이미지로 만들어 주세요. 이미지를 만들 수 없으면 같은 크기의 HTML로 만들어 주세요.

- 한 장에 메시지 하나, 강조색은 한 곳
- 배경색 [예) 아이보리] / 글자색 [예) 검정] / 강조색 [예) 파랑], 글꼴 [예) Pretendard], 8장 모두 같은 여백과 글자 크기
- 글에 없는 숫자나 후기는 넣지 않습니다
```

> 이미지 만들기가 사용 한도에 걸리면 같은 규칙으로 HTML을 만들어 달라고 하세요. HTML은 이 폴더의 `template/`처럼 브라우저로 열어 캡처하거나 스크립트로 이미지로 뽑을 수 있습니다.

## 마음에 안 들면 이렇게 말하세요

- "1번 장 제목이 설명 같아요. 결과가 보이는 문장으로 두 개만 다시 제안해 주세요."
- "4번 장 글자가 이미지 밖으로 잘렸어요. 본문을 한 줄로 줄여 주세요."

## HTML 템플릿 쓰는 법

1. `template/card-01.html`을 브라우저로 열어 모양을 봅니다.
2. 글자를 바꾸려면 HTML 파일에서 `class="title"`(큰 제목), `class="body"`(본문), `class="panel-title"`(위 패널 제목) 안의 문장만 바꿉니다. 강조할 단어는 `<span class="hl">단어</span>`로 감쌉니다.
3. 색을 바꾸려면 `template/card.css` 위쪽 `--bg`(배경) `--ink`(글자) `--accent`(강조) 세 줄만 바꿉니다.
4. 이미지로 뽑기 (Chrome·Chromium·Edge 중 하나 필요):

```bash
bash 02-알리기/2-카드뉴스/template/render.sh        # 전부
bash 02-알리기/2-카드뉴스/template/render.sh 01 03  # 골라서
```

결과는 `02-알리기/2-카드뉴스/output/card-NN.png`에 저장됩니다. 화면에 `"problems":[]`가 나오면 글자가 카드 밖으로 넘치지 않은 것입니다.

윈도우는 **Git Bash**(설치하면 생기는 `Git Bash` 앱)에서 같은 명령을 실행하세요. `저장됨` 대신 경고가 뜨면 PNG가 오류 화면일 수 있으니 파일을 열어 확인합니다.

스크립트를 못 쓰는 환경이면: HTML을 브라우저로 열고 개발자 도구의 기기 크기를 1080x1350으로 맞춘 뒤 화면 캡처하세요.

## AI 도구(Claude Code·Codex)가 진행할 때

1. 레퍼런스 캡처가 있으면 분석해서 규칙을 만들고, 없으면 `규칙-예시.md`를 기본 규칙으로 쓸지 묻는다.
2. 장별 기획표를 먼저 보여주고 확인을 받는다.
3. 확인되면 `template/`을 `내작업/카드뉴스/`로 복사해 문장을 바꾼다. 키트 원본 템플릿은 고치지 않는다.
4. 복사한 폴더에서 `bash render.sh`를 실행해 PNG를 만들고, `problems`가 빈 배열인지 확인한다. 넘친 장은 문장을 줄여 다시 뽑는다.
5. 브라우저가 없거나 실행이 막히면 HTML을 열어 캡처하는 방법을 안내한다.
