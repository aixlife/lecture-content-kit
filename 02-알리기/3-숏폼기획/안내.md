# 3 · 숏폼 기획 대본

**하는 일** 글을 45~55초 세로 영상 대본으로 바꿉니다. 사람이 고르는 건 세 가지입니다: **첫 3초 문장, 대본, 강조할 단어.**

**준비할 것**

- 블로그 글 또는 카드뉴스 기획표

**이 폴더의 파일**

- `예시-대본.md` — 표 형식 대본 예시 (형식만 참고하세요)

## 복사할 프롬프트 · 숏폼 대본 만들기

```text
아래 글로 45~55초짜리 세로 숏폼 대본을 만들어 주세요.

글: [블로그 글 또는 카드뉴스 기획표 붙여넣기]

규칙
- 문장 하나 = 자막 한 장면 = 나레이션 한 줄
- 한 문장은 40자를 넘기지 않기
- 첫 3초에 던질 문장 후보 3개를 먼저 보여 주기
- 표로 정리: 번호 / 구간(첫 3초·전환·본문·마무리) / 자막 / 화면에 보일 것
- 표 아래에 자막 전체 글자 수와 예상 길이(초)를 적기
- 장면마다 자막에서 강조할 단어 하나 표시
- 글에 없는 숫자나 성과는 넣지 않기
```

## 복사할 프롬프트 · 첫 3초만 다시 고르기

```text
위 대본의 첫 3초 문장을 다시 제안해 주세요.

- 후보 5개, 각 20자 이내
- 유형을 섞기: 결과를 먼저 말하기 / 흔한 실수 짚기 / 질문 던지기
- 글에 없는 숫자나 약속은 쓰지 않기
- 후보마다 이 문장 다음 장면과 자연스럽게 이어지는지 한 줄로 평가
```

## 마음에 안 들면 이렇게 말하세요

- "첫 3초는 후보 2번으로 하고, 전체를 45초 안으로 줄여 주세요."
- "7번 문장은 소리 내 읽으면 어색해요. 말하듯이 바꿔 주세요."

## 영상으로 만드는 법 (안내만)

이 키트는 기획 대본까지 다룹니다. 영상 제작은 아래 중 편한 쪽을 고르세요.

**설치 없이 하기 (추천)**

- 휴대폰으로 대본을 읽으며 직접 촬영하고, 쓰던 영상 편집 앱의 자동 자막 기능으로 자막을 붙입니다. 강조 단어만 색을 바꿉니다.
- 목소리를 녹음한 파일을 자막 자동 생성 기능이 있는 편집 앱에 넣고, 대본 표를 보며 장면을 나눕니다.

**코드로 만들기 (Claude Code·Codex 사용자)**

- HyperFrames — https://github.com/heygen-com/hyperframes
  HTML로 만든 화면을 영상으로 렌더하는 오픈소스입니다. 설치와 사용법은 그 페이지의 공식 안내를 따르세요. AI 도구에게 "HyperFrames 공식 README 읽고 이 대본으로 세로 영상 만들어줘"라고 요청할 수 있습니다.
- Qwen3-TTS — https://github.com/QwenLM/Qwen3-TTS
  대본을 나레이션 음성으로 읽어 주는 오픈소스입니다. 컴퓨터 사양이 필요합니다. 다른 사람의 목소리를 허락 없이 흉내 내지 마세요.

> 긴 문장을 음성으로 만들면 속도가 흔들리기 쉬워서, 한 문장을 40자 안쪽으로 끊는 규칙을 둡니다.

## AI 도구(Claude Code·Codex)가 진행할 때

1. 글을 받아 첫 3초 후보 3개를 먼저 보여주고 고르게 한다.
2. 고른 후보로 표 대본을 만들어 `내작업/숏폼-대본.md`로 저장한다. 문장마다 40자 이하인지 세어서 확인한다.
3. 영상 제작을 원하면 위 "영상으로 만드는 법"을 보여주고 사용자가 경로를 고르게 한다. 유료 서비스나 설치가 필요하면 먼저 알린다.
