# 02 · 소스 하나로 알리기

강의를 만들고 끝내면 아무도 모릅니다. 그렇다고 블로그 따로, 스레드 따로, 카드뉴스 따로 채널마다 새로 쓰면 금방 지칩니다. 강의 원고 하나를 늘리고 줄여서 전부 만듭니다.

```
강의 원고 ─┬─ 늘리기 → 블로그 긴 글
           ├─ 줄이기 → 스레드 짧은 글
           ├─ 장면으로 → 카드뉴스
           ├─ 대본으로 → 숏폼 기획
           └─ 강의 녹음 → 받아쓰기 → 다시 글
```

| 순서 | 폴더 | 하는 일 |
|---|---|---|
| 1 | `1-블로그-스레드/` | 원고를 블로그 긴 글·스레드 짧은 글로, 마지막에 AI 티 걷어내기 |
| 2 | `2-카드뉴스/` | 좋아 보이는 카드뉴스를 분석해 규칙으로 만들고, 내 글을 카드뉴스로 |
| 3 | `3-숏폼기획/` | 45~55초 세로 영상 대본, 첫 3초 문장, 강조 단어 |
| 4 | `4-녹음을글로/` | 강의 녹음을 받아써서 다시 글·전자책 목차로 |

**시작 재료**: 1부에서 만든 구조 설계서나 프롬프터, 또는 강의 내용을 요약한 원고 한 장. 원고 예시는 `1-블로그-스레드/예시-원고.md`.

## 원칙

- 새로 쓰지 않고 원고를 늘리고 줄인다.
- 원고에 없는 숫자·후기·성과는 만들지 않는다.
- 마지막 손질은 사람 몫이다. 내 말투로 한 줄씩 고친다.
- 게시는 직접 한다. AI는 초안까지만.
